# rd.igoodlife.com 运维辅助油猴脚本

给公司雷达平台（智慧康养管理平台）补充运维层面的可视化和便捷功能。

- 平台的架构、接口、样式和机构模型分析见 [docs/site-analysis.md](docs/site-analysis.md)
- 测试机构：**李虎**（平台 / 福慧康电子科技有限公司 / 内部测试 / 李虎）
- 轻量桌面客户端（用户端"康养看护" + 运维端"雷达运维"）在 [client/](client/README.md)

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 Tampermonkey 管理面板 → "+" 新建脚本 → 把 `scripts/` 下对应 `.user.js` 文件的全部内容粘贴进去 → 保存
3. 刷新平台页面

## 脚本列表

### 房间姿态回放 `scripts/room-posture-replay.user.js`

**入口**：实时监测 › 房间详情。房间标题右侧的"轨迹回放 / 热力图 / 事件记录"图标后面会多出一个"姿态回放"图标（右上角有个小蓝点）。

和平台自带的"轨迹回放"相比：

| | 平台轨迹回放 | 姿态回放（本脚本） |
|---|---|---|
| 时间段 | 只能选一天 | 任意开始/结束时间，可跨天（最长 7 天） |
| 姿态 | 无 | 人员点按姿态着色并显示文字，告警类姿态（疑似跌倒、跌倒确认、坐地、床上坐起告警）有脉冲高亮 |
| 时间轴 | 固定 24 小时，不能缩放 | 可缩放到秒级：滚轮缩放、拖动平移、单击定位、双击放大，顶部全局导航条 |
| 事件 | 无 | 进出房间 / 区域 / 监护区事件和告警姿态的列表，点击即可跳转 |
| 多目标 | 按人员筛选 | 每个目标一条泳道，各自显示姿态时间段 |

**操作**

- 空格：播放 / 暂停
- ← / →：后退 / 前进 1 秒（按住 Shift 为 10 秒）
- `+` / `-`：放大 / 缩小时间轴
- Esc：关闭
- 倍速 0.5x～120x；尾迹长度可调；"跳过无人时段"会在播放时自动跳过没有数据的时间
- 房间平面图可以用滚轮缩放、拖动平移

**数据来源**

- `/api/room-view/v3/detail`：房间、家具、雷达区域
- `/api/human-exists/trajectory-points`：轨迹点，单位 cm，坐标与房间一致
- `/api/device/human-position/posture-timeline`：姿态时间段（按 24 小时分段请求）
- `/api/device/human-position/event-timeline`：事件（按 24 小时分段请求）

脚本只读取数据，不会修改平台上的任何内容。

### 安装角度检查 `scripts/room-install-angle.user.js`

**入口**：实时监测 › 房间详情。房间标题右侧会多出一个"安装角度"图标（尺子图标，右上角有小蓝点）。

**判定标准**（定义在脚本开头的 `STANDARDS` 常量里，可以直接修改）：

| 安装方式 | angle_x | angle_y | angle_z | 允许偏差 |
|---|---|---|---|---|
| 侧装 | 0° | 68°（俯角 = 90° − y = 22°） | 22°（y + z = 90°） | ±2° |
| 顶装 | 0° | 0° | 90° | ±3° |

- 安装方式默认取自房间布局里的雷达配置（`qingLanConfig.installType`），也可以在弹窗里手动切换。没有配置的默认按侧装检查。
- 状态分三档：偏差超过允许值为"超限"（红），超过允许值的 75% 为"临界"（黄），其余为"正常"（绿）。

**弹窗内容**

- 总结论（合格 / 接近临界 / 超出范围，以及具体哪个轴偏了多少）
- 三轴明细表：当前值、标准值、允许范围、偏差；侧装时 y 轴额外显示俯角
- 侧视图：侧装显示俯角，顶装显示 z 轴与水平面的夹角，绿色扇形是允许范围
- 水平仪：两个轴相对标准值的偏差，气泡落在绿色圈内即合格
- **空间姿态（3D）**：用三个角度还原设备的倾斜姿态，显示设备盒子、+X/+Y/+Z 三根轴、竖直参考线和水平参考面
  - 每根轴到水平面画一段夹角弧线并标注角度，标注框颜色表示状态（绿 / 黄 / 红）
  - 虚线是标准姿态，方便和实际姿态对比
  - 拖动旋转，滚轮缩放，双击复位；可切换"正视 / 侧视（沿 x 轴）/ 俯视"，侧视最适合看侧装俯角
  - 加速度计测不出绕竖直轴的水平朝向，所以图中固定让设备 x 轴朝右，只用来看倾斜，不代表设备在房间里的实际朝向
- 角度趋势：最近 30 分钟 / 2 小时 / 6 小时 / 24 小时的三轴曲线和标准色带，超限的点标红，鼠标悬停可以看具体数值
- 房间里有多台设备时，可以在顶部切换

**数据来源与刷新**

- 角度来自设备心跳 `Device.heartbeat` 的 `params.install = [angle_x, angle_y, angle_z]`，通过 `/api/device-log/pages` 按 SN 查询
- 设备约每分钟上报一次。平台没有主动读取角度的接口，所以弹窗每 5 秒查询一次最新心跳，**显示的角度最多比实际晚约 1 分钟**。弹窗会显示"最近上报时间"和"预计下次上报"倒计时
- 只读，不会向设备下发任何指令
